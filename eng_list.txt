?:warning and summaries:
This is a english list for the Raspberry pi 1 degrees of freedom tracking robot,Links for  tools and materials are more for reference than a nessecary link.You cna find the required tools else if you want,
,the tutorial is with the raspberry pi camera module in mind but there is also code for usb camera(optional) in repo.But there is no specific usb camera holder currently.
If there is something wrong please reply if possible.

Required software:

opencv c++ version for the Raspberry Pi ( https://opencv.org/get-started/?utm_source=opcv&utm_medium=home ),lccv for Raspberry Pi camera ( https://github.com/kbarni/LCCV.git ),
PIPCA9685 software for the Raspberry Pi ( https://github.com/barulicm/PiPCA9685.git ),
vnc viewer for pc/laptop ( https://www.realvnc.com/en/connect/download/viewer/?lai_sr=0-4&lai_sl=l&lai_p=1&lai_na=488119 ),
vscode or other editor for c++ and cmake and Raspberry Pi (optional).
Recomended skills:
c/c++ programming,ssh into a Raspberry Pi with vnc viewer,
using opencv in c++,Aquiring 3d printed parts or making parts,
screwing parts together.Working with 5V power supplies.
